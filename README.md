> A simple classroom tool that randomly selects students from a class roster.

## 📌 Overview

The Random Name Generator allows teachers to upload a **CSV file containing student names** and randomly select students from the class.

Instead of manually choosing students, the tool provides a quick and simple way to randomly call on students during class.

### How It Works

1. Upload a CSV file containing student names.
2. Generate a random selection.
3. Use the selected name for classroom participation, activities, or other assignments.
